# 雑学メモ

うんちく・雑学を記録して、スマホでいつでも見返せる個人用メモアプリです。
プログラミングの知識がなくても使えるように、スマホのブラウザだけで動きます。

## できること

- 📋 **一覧・検索** - 登録したうんちくを一覧表示、キーワードやカテゴリで絞り込み
- 🎲 **ランダム表示** - 誰かに話したいときに、パッと1つ選んで表示
- ➕ **追加・編集・削除** - タイトル、詳しい内容、カテゴリ、タグ、出典を記録
- 💾 **バックアップ** - データをファイルに書き出し／読み込み

データはこのアプリを開いたスマホ・ブラウザの中だけに保存されます（サーバーには送信されません）。
機種変更やブラウザのデータ消去に備えて、たまに「バックアップ」タブから書き出しておくことをおすすめします。

## 公開のしかた（最初の1回だけ）

このリポジトリを GitHub Pages で公開すると、あなた専用のURLでアプリを開けるようになります。

1. GitHubでこのリポジトリの **Settings** を開く
2. 左メニューの **Pages** を選ぶ
3. 「Build and deployment」の **Source** を **GitHub Actions** にする
4. `main` ブランチに変更が反映されると、自動でアプリが公開されます
5. 数分後、Pagesの画面に表示されるURL（`https://ユーザー名.github.io/zatsugakumemo/` のような形）を開く

公開されたURLをスマホのSafari/Chromeで開き、共有メニューから
「ホーム画面に追加」をするとアプリのように使えます。

## スマホでの使い方

- 下のタブで画面を切り替えます：**一覧 / ランダム / 追加 / バックアップ**
- 新しいうんちくは「追加」タブから登録
- 一覧の項目をタップすると詳細が開き、そこから編集・削除ができます
- 会話のネタを探したいときは「ランダム」タブでカテゴリを選んで「ネタを引く」
